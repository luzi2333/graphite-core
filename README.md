# 石墨芯 Android

把网页版可视化装进一个原生壳里，**直接抓手机内部音频**（戴耳机也能抓，不需要外放、不需要屏幕共享）。

## 和网页版的区别

| | 网页版 | 这个 App |
|---|---|---|
| 声源 | 要授权屏幕共享，或麦克风，或拖文件 | 打开即抓系统音频 |
| 戴耳机 | 桌面可以，手机不行 | **可以** |
| 授权 | 每次弹屏幕选择框 | 每次启动一次系统「录制」确认 |
| 界面 | 完整面板 | 同样的面板，音频区只剩「系统音频 · 自动抓取中」 |

## 工程结构

```
default-workspace/
  graphite-core/        ← 网页（视觉、交互全在这里）
  graphite-android/     ← 本工程，构建时自动把 ../graphite-core 拷进 assets
```

**两个文件夹必须保持同级。** 改了网页代码不用复制，重新构建 App 就会带上最新版。

## 构建

1. 装 **Android Studio**（Koala / 2024.1 以上）和 JDK 17（Studio 自带）
2. `File → Open`，选中 `graphite-android` 文件夹
3. 第一次会提示 Gradle 同步，等它下载依赖（AGP 8.5 / Kotlin 1.9）
4. 手机开「开发者选项 → USB 调试」，连上电脑
5. 顶部设备列表选你的手机，点 ▶ Run

没有 Gradle Wrapper，Android Studio 会问用哪个 Gradle，选它推荐的版本即可。命令行构建需要自己 `gradle wrapper` 生成一次。

最低支持 **Android 10（API 29）**，因为 `AudioPlaybackCapture` 是 10 才有的。

## 首次启动

1. 弹出「允许石墨芯访问此设备上的音频吗」→ 允许（录音权限）
2. 弹出「开始录制或投放」系统确认框 → 立即开始（这个框每次启动都会出现，Android 14 起每个会话都必须确认）
3. 确认后画面开始跟音乐跳

之后播放任何音乐 App 都行——网易云、QQ 音乐、B 站、YouTube 都可以。

## 已知限制

- **有些 App 录不到**：如果音乐 App 声明了「不允许被录制」（`ALLOW_CAPTURE_BY_NONE`），或者内容有 DRM（Netflix 等），抓到的是静音。国内主流音乐 App 通常没这个限制。
- **每次启动都要点一次系统确认**：Android 的安全模型决定，无法自动续期。
- **只能录媒体声音**：通话、闹钟、提示音不在捕获范围内。
- **iOS 做不了**：系统不允许第三方 App 抓其他 App 的音频。

## 打安装包

`Build → Generate Signed Bundle / APK → APK`，按提示生成一个签名（自己用随便填），产出的 apk 可以直接发给 Android 手机装。

## 排查

| 现象 | 原因 |
|---|---|
| 画面是平的、不跳 | 没授权录制，或当前音乐 App 禁止被录制 |
| 第一次就报「需要录音权限」 | 权限被拒，去系统设置里手动打开麦克风权限 |
| 构建报 `../graphite-core` 找不到 | 两个文件夹不在同一层 |
| 编译报 AGP/Gradle 版本不匹配 | 把 `build.gradle.kts` 里的 AGP 版本调成 Studio 推荐值 |

# 石墨芯 · GRAPHITE CORE

跟着音频跳动的 RBMK 石墨堆芯上盖板。一整面方形钢板铺在圆盘里，每块钢板独立抬起、落回，像一层被声音顶起来的砖。外圈是带铆钉、危险条纹和钢印编号的重型钢环，地面是厂房混凝土。整体走苏联重工业那种冷、旧、沉的调子。

**可以直接跟电脑里正在放的音乐跳**——网易云、Spotify、QQ 音乐、浏览器里放什么都行。

零依赖、无构建、离线可用。

## 打开

双击 `index.html`（Chrome / Edge）。

## 三种声源

| 方式 | 说明 |
|---|---|
| **捕捉电脑声音** | 点面板里这个按钮，在弹窗里选「**整个屏幕**」，**勾选底部的「分享系统音频」**，然后点「分享」。之后电脑里放什么，盖板就跟着跳 |
| **麦克风** | 手机、桌面都能用：浏览器用麦克风听周围的声音（包括手机外放的歌）。适合手机端，或者不想共享屏幕的时候 |
| **载入音频** | 拖一个 mp3 / wav / ogg / flac 进来，或点按钮选文件 |
| **演示信号** | 124 BPM 的程序化节拍，不放歌也能调参数 |

### 关于捕捉电脑声音

浏览器不允许网页自己偷听系统声音，必须你手动授权一次，这是安全限制，绕不过去。页面能做的只是**把弹窗预置成「整个屏幕 + 分享系统音频」**，但浏览器仍然会弹框让你确认——没有任何网页 API 能跳过它。

要点：

1. 用 Chrome 或 Edge（Safari / Firefox 拿不到系统声）。
2. 弹窗里选**整个屏幕**，不要选单个窗口或标签页。
3. 底部「分享系统音频」必须勾上——Win 上默认可能是关的。
4. 开始后浏览器顶部会有「正在共享」的提示条，这是正常的；点面板里变成「停止捕捉」的按钮可以结束。
5. 如果双击打开（`file://`）时按钮没反应，在这个文件夹里跑一句 `python -m http.server 8000`，然后打开 `http://localhost:8000`。

**戴耳机也能抓，不需要外放。** 它抓的是系统输出的混音（loopback），不是麦克风。唯一要求是音乐播到系统**默认输出设备**——如果你在网易云里单独指定了别的声卡/耳机，可能抓不到，改回默认设备即可。

### 手机端

手机浏览器**不能**抓系统声音：Android Chrome 根本没有这个 API，iOS Safari 共享屏幕也不带音频。手机上：

- 用「**麦克风**」听外放的声音（**戴耳机会听不到**，麦克风只收空气里的声音）
- 或者把音频文件存到手机里，用「载入音频」播放
- 触摸操作：单指拖动环绕，**双指捏合缩放**


## 分享给别人玩

纯静态项目，把 `graphite-core` 整个文件夹传上去就有链接了。

**方式一：静态托管（推荐）**

Cloudflare Pages / Vercel / Netlify / GitHub Pages 都行：把文件夹拖进去或连仓库，几十秒出链接，自带 HTTPS，访客不用装任何东西。

**方式二：本机起服务 + 内网穿透**

```bash
# 在本文件夹里
python -m http.server 8000
# 另开一个窗口，任选其一
cloudflared tunnel --url http://localhost:8000
ngrok http 8000
```

会拿到一个 https 链接。缺点：电脑得一直开着，免费隧道地址会变、速度一般。

**方式三：路由器端口映射**

把 8000 端口映射到公网，别人访问 `http://你的IP:8000`。多数家庭宽带没有公网 IPv4，而且 http 下拿不到系统声音，不推荐。

### 两个必须知道的点

1. **系统声音捕捉要求 HTTPS（或 localhost）**。用 `http://公网IP:端口` 打开时浏览器不会暴露 `navigator.mediaDevices`，「捕捉电脑声音」会直接不可用；拖本地文件、演示信号不受影响。
2. **声音是每个访客自己的**。页面不会把你这边的音乐传给别人——每个访客拖自己的文件，或者授权捕捉自己电脑的声音。

如果你想要的是「别人打开链接就能听到我在放的音乐」，那需要另外做音频推流（WebRTC 或直播流），不是这个静态页能解决的。

捕捉到的声音**不会**再从扬声器播一遍（内部接了静音增益），所以不会和网易云打架。

## 它是怎么动的

不是发光、不是泛光，是**几何位移**：每块钢板按自己频段的能量，从盘面里抬起来，露出两侧的金属侧壁和缝隙里的黑影，再落回去。抬得越高，侧壁越长。

抬升走「本帧归一化 + 落差曲线」：每帧先找当前场里的最大能量，把所有能量按它归一化，再用幂曲线分配高度。这样无论灵敏度拉多高，都不会所有块一起顶到上限变成一块平板——永远有高的、也有贴地的。

`频谱 24 段 → 每段包络（起音快 / 落音慢）→ 每块取自己那一段 → 乘规律场 → 除以本帧最大值 → 落差幂曲线 → 抬升高度`

内圈吃低频，外圈吃高频（可切成环向分频）。

## 面板

### 跳动

| 控件 | 作用 |
|---|---|
| 幅度 0–300% | 抬升高度倍数；0 就是一整面静止的盖板 |
| 落差 0–200% | 高低差。100% 默认；往右拉，高的更高、矮的更贴地；往左拉，所有块趋于同一高度 |
| 规律 | 8 种抬起规律 |
| 灵敏度 0.2–3× | 整体高度增益；拉高以后所有起伏都更大 |
| 波速 0–3× | 海浪 / 扩散 / 螺旋的推进速度 |
| 惯性 0–2 | 包络软硬；0 硬跟拍，2 慢起伏 |

### 规律

| 名称 | 观感 |
|---|---|
| 中心扩散 | 从圆心一圈圈向外推的环状抬升（默认） |
| 海浪 | 斜向长波扫过整块盖板 |
| 随机 | 每块独立随机弹起 |
| 以中心为准 | 中心抬得最高，向外递减 |
| 向心收缩 | 环状波动从外圈收向圆心 |
| 对称镜像 | 左右镜像同步抬起 |
| 螺旋 | 一条螺旋线扫过盘面 |
| 呼吸 | 整块盖板同步起伏 |

### 外观

| 控件 | 作用 |
|---|---|
| 大小 55%–125% | 圆盘直径。块的大小基本不变，圈越大块越多（55% 约 430 块，100% 约 1220 块，125% 约 1900 块）；而且**圈越大，跳得越高** |
| 拖动画面 | 左右拖 = 360° 环绕；上下拖 = 抬高压低俯角，压到接近水平就停住，不能从底下看 |
| 频段 径向 / 环向 | 内低外高，或按扇区分频 |
| 配色 | 轧钢·军绿混排 / 军绿漆 / 铸铁 / 氧化钢 |

### 效果

彩色标块（黄、红、白、黑、绿的检查标记）、数值 HUD。

## 质感是怎么做的

- 每块钢板是一张 64×64 的程序化贴图：拉丝、油污、锈斑、四角铆钉、左右上下倒角，缩放到块大小
- 8 种色调对应 8 张贴图，按哈希均匀分给所有钢板，其中约 25% 是军绿漆或锈蚀板
- 抬起的板会吃到一点顶光，露出的正面和右侧面是压暗的金属色
- 外圈：重钢环 + 4 段黄黑危险条纹 + 三圈铆钉 + 径向拼缝 + 钢印编号（07 / 12 / 18 / 23）
- 地面：混凝土分格缝、油污、磨旧的黄色安全线、俄文地坪钢印（РБМК-1000 / ОПАСНАЯ ЗОНА / 4-Й БЛОК）
- 没有任何后期滤镜：颗粒、暗角、色差、泛光全部去掉了

## 视角

画面里直接拖：

- **左右拖**：绕着堆芯转，360° 无缝；画面跟着手指走，往左拖就往左转
- **上下拖**：往下压 = 更像俯视，往上抬 = 压向地面
- **滚轮**：缩放画面 45%–280%，只改变观看大小，不改变方块数量
- **双指捏合**（手机 / 触控板）：同样缩放；单指拖动仍然是环绕
- 俯角限制在 **6°–86°**：拖到快贴地平线就停住，**不会钻到地板底下仰视**
- 松开鼠标后视角和缩放会记在本地下次打开还在

旋转是真正的环绕：方块阵列跟着转，钢环保持水平椭圆，地面钢印也跟着转。

## 文件结构

```
graphite-core/
  index.html
  css/style.css
  js/audio.js      音频：本地文件 / 系统声音捕捉 / 演示信号 / 频谱 / 包络
  js/lattice.js    方形钢板栅格 · 色调/标块/开口 · 深度排序
  js/patterns.js   8 种抬起规律
  js/renderer.js   环绕相机 / 场地 / 钢板贴图 / 立方体抬升 / 外圈钢环
  js/ui.js         面板 / 拖放 / 快捷键 / 波形概览
  js/main.js       状态 · 主循环 · 抬升映射
  js/post.js       已废弃，未被引用，可直接删除
```

抬升几何：顶面上移 `z·0.85·scale`、向右错开 `0.22·L`，正面和右侧面补两个四边形。绘制按 `y` 从远到近，抬起的板自然盖住后面的板。

## 调参建议

- 想看清一块块弹：幅度 130%、灵敏度 1.8、惯性 0.5、视角 40°、规律「随机」
- 跟上流行歌的鼓点：幅度 160%、灵敏度 1.5、惯性 0.4、规律「中心扩散」
- 想要那种安静的厂房感：幅度 60%、灵敏度 0.8、惯性 1.6、视角 66°
- 低频重的电子乐：幅度 200%、规律「中心扩散」

## 性能

钢板数量随「大小」自动变化：55% 约 380 块，100% 约 1130 块，125% 约 1800 块。1080p 桌面核显跑 60fps 没问题；掉帧就把大小调小，或关掉彩色标块。

## 已知限制

- 系统声音捕捉必须手动授权，且只有 Chrome / Edge 在 Windows 上支持。
- 浏览器不能后台自动开始捕捉，每次打开页面都要点一次。
- 高视角下（>72°）侧壁很薄，抬起的立体感会弱，这是几何决定的。
- 极端高 DPI 会被压到 1.5 倍渲染。
